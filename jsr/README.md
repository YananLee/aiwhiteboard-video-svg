# aiwhiteboard-video-svg

A small local SVG generator associated with [AIWhiteboard.Video](https://aiwhiteboard.video/). It does not call the product website or export service.

Install: `npx jsr add @yananlee/aiwhiteboard-video-svg`. Import `renderTitle` from `@yananlee/aiwhiteboard-video-svg` and render SVG using your own text.
